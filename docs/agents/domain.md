# Domain Docs

This repository has one domain context. Read [architecture §9](../architecture.md#9-术语与来源) for terminology and [§6](../architecture.md#6-关键决策台账编号--内容--出处) for design decisions before naming concepts or proposing changes.

Use the same terms in issues, proposals, and tests. If a proposal contradicts a recorded decision, cite it and explain why it should be reopened.

If a root `GLOSSARY.md` or relevant `docs/adr/` record exists, consult it too. Do not create empty files to satisfy a skill convention; keep each definition or decision in one place.
